# Anonymous manuscript and reproducibility materials

**Embodiment Adaptation of Vision-Language-Action Models from Proprioceptive Residuals**

`VLA_ICLR_revised.pdf` is the checked 48-page manuscript. The numbered text runs to page 9 with three lines carrying onto page 10; statements, 2 reference pages and 35 appendix pages follow. The main-text page boundary is still being settled. The exact PDF in this archive has no embedded/associated files or C2PA marker and blank author metadata. `CHECKSUMS.sha256` records its bytes and the release files. The manuscript retains its AI-use disclosure and normal literature attribution.

## Build the editable paper

Use TeX Live with latexmk, or upload this folder to Overleaf and choose `paper/main.tex`:

```bash
cd paper
latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex
```

All active TeX inputs, bibliography/style files, five used vector PDF figures,
and the TikZ source for Figure 1 are included. The build needs no robot
evaluation data. The included conference style is inherited from the project;
this package does not certify compliance with a particular submission
deadline's rules.

## Reproducibility

`reproduction/` contains constructed numerical checks, their precomputed results, aggregate count ledgers, figure utilities, and empty logging templates. See its README for dependencies and commands. `IMPLEMENTATION_MANIFEST.md` identifies unresolved empirical configurations and the required physical-model checks.

Original VLA evaluation code, calibration arrays, and raw episodes were not supplied. The reported VLA experiments have not been independently rerun by this revision. Constructed servo checks do not establish contraction or contact bounds for the evaluated manipulation environments. No new task-success result is generated by these scripts.

Figure 1 is an editable TikZ mechanism diagram of the evaluated
prediction-only adapter. It contains no empirical scene panel, historical
cohort, or unevaluated composite-control path. Historical archives, unused
artwork, and private editorial/recovery records are excluded from this package.
