# Development-selection ledger for the ICLR 2027 manuscript (`iclr2027/`)

Queue item Q6, writing part. Compiled 2026-09-15 on branch `review/dual-track-audit` at `a8b56bb`, read-only, CPU only.
Every entry is sourced from a primary record: a dated section of `docs/ADAPTIVE_CONTROL_VLA.md` (cited as `record §n l.a–b`,
line numbers at HEAD), a commit, a preregistration in `prereg_records/`, or a run configuration (the runner's saved `args`
in `result.json` / `run_configuration.json`, which are authoritative over reconstructed command strings). Where a value or its
selection basis could not be found in any of these it is marked **unsourced**; nothing below is inferred.

Supporting files written for this task (the only files touched): `codex_prompt/ledger_work/result_args_dump.md` (the saved
`args` of all 74 `result.json` files), `codex_prompt/ledger_work/SOURCES.md` (every primary record consulted), this report.

## Conventions

**Data classes.** *healthy only* = fitted or measured on fault-free rollouts with no task outcome consulted; *development* =
chosen from runs that were not the reported cells; *faulted development* = chosen after inspecting task outcomes or
estimates of faulted runs; *fault-informed* = set as a function of the injected fault magnitude (privileged, though not
outcome-tuned); *confirmation* = the cohorts the manuscript's tables and text report.

**The manuscript's confirmation cohorts** (from `iclr2027/evidence/manifest.json` and the appendix): the reference-calibration
headline cells `results/suites/libero_{spatial,object}_rotonly_paired.json` (n=20, inits 45/46, run 2026-09-01) and
`libero_{goal,10}_rotonly_n40.json` (n=40, inits 45–48, 2026-09-04); the disjoint-calibration cells `results/heldout/*`
(same scenarios, 2026-09-11); healthy controls `re4_evidence/C_healthy` (2026-09-11); the gate cells `results/gate/*`
(2026-09-10); the OFT/GR00T transfer cells `results/oft`, `results/groot` (2026-09-03, 09-06/07); the update table
`re4_evidence/F_held_vs_continued` (ALOHA seeds 200–239, GR1 seeds 100–129; 2026-09-12); the decision table
`re4_theory/8_statistics` (libero_10 inits 42–49, Spatial 45/46; pinned; 2026-09-13); the allocation table
`results/joint_followup/confirmation_plan` (inits 35/36; 2026-09-08); the friction/lock rows `results/jf_rerun`
(inits 45–48; 2026-09-11); the descriptor cells `results/sweep`, `results/descriptor` (inits 37/38; 2026-09-09); the ALOHA
observer comparison `results/composite_tuning` (seeds 3400–3429); the theory-evidence cohorts `re4_theory/{1_contraction,
2_metric,6_ry,telemetry}` (2026-09-13); WidowX `results/widowx` (seeds 100–122; 2026-09-09).

**Where the saved args do not exist.** The 2026-09-01/04 headline files, `results/phase05/*`, `results/oft/*` and
`results/groot/*` store only `gamma` (and, for n=40, `f_true`). Their constants are those recovered by
`results/re4_evidence/A_provenance/implementation_map.md` (record §42) from the operator's session transcript and pinned
forensically against the stored per-step estimates (the ρ/2 bound of the legacy law, projection rails, leakage-firing
counts). The ledger cites that map for those cohorts and says so in the status column.

**Status codes.** `S` = value, first appearance and selection basis all sourced; `S/U` = value and first appearance sourced,
selection basis or rationale unsourced; `U` = value itself unsourced.
